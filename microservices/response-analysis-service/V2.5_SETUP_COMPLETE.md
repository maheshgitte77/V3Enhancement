## 📊 Architecture Comparison

| Aspect                   | V2               | V2.5                       |
| ------------------------ | ---------------- | -------------------------- |
| **Configuration**        | V2_CONFIG        | V2_5_CONFIG (independent)  |
| **Stage 1**              | Combined         | Behavioral/Typing Analysis |
| **Stage 2**              | Combined         | Technical Scoring only     |
| **Stage 3**              | Combined         | Cheating Detection only    |
| **Communication Rating** | Text-based guess | From actual media          |
| **Confidence Level**     | Estimated        | From vocal/visual cues     |
| **Relevance Breakdown**  | Generic          | Time-based with timestamps |
| **Modularity**           | Coupled to V2    | Fully independent          |
| **Testability**          | Difficult        | Easy (isolated)            |

## 🐛 Troubleshooting

### V2.5 Not Initialized

**Problem**: `"V2.5 processor not initialized"` error

**Solution**: Check that `workers/responseWorkerV2.js` is being loaded correctly and V2.5 initialization is called

### File Upload Issues

**Problem**: File upload fails

**Solution**:

- Check file size limits
- Verify `Uploads/` directory exists
- Check disk space

### Stage Timeout

**Problem**: Processing times out

**Solution**:

- Increase stage timeout in V2_5_CONFIG
- Check network connectivity to AI service
- Verify file accessibility
